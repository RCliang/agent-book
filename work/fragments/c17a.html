LLM 智能体训练AGENT RL · TRAJECTORY BUFFERS · PARADIGMS

标准 RLHF 只优化单轮应答；自主智能体要跨 10–100+ 次工具调用规划，reward 稀疏且来自真实执行——轨迹缓冲区 e=(S,A,R,S′) 存下整条轨迹，再经三种范式转化为能力。

01轨迹缓冲区
Token 化文本替代张量：CoT 推理＋结构化工具调用；规模 10³–10⁵ 条，状态 1K–128K token，reward 来自执行环境。
02范式 A · 自我纠正
失败轨迹生成显式文本批评；修正后入最优经验池，以 SFT 或 GRPO 更新权重。代表：STaR·Reflexion。
03范式 B · 离策略探索
自主探索数千条路径；成功过滤·效率排序·多样性采样，只在高质轨迹上算 Loss。代表：ReAct。
04范式 C · 经验 RAG
缓冲区作向量库，Top-k 成功经验注入 Prompt，零训练即时适配；罕见用检索，常见用 RL。
方法核心思想（一句话）信号来源
STaR迭代 SFT：在自身成功轨迹上自举推理；失败题以正确答案为条件「合理化」，3–5 轮收敛答案 / 测试正确性
Reflexion上下文 RL：语言式自我批评存入情节记忆（m≤3），零权重更新评估器二元成败
ReActPrompt 范式：单次生成内交错「思考」与「行动」；格式惩罚写入 reward环境观测（逐步）
LATS树搜索：动作序列上做 MCTS（UCB1）反向传播；WebShop 40%→75%终端 reward 反向传播
AgentQ离策略 RL：MCTS 产出多样轨迹，按 reward 构造偏好对做 DPO；WebShop 50%→82%同任务轨迹排序
Voyager技能库：存取已验证代码函数，检索组合复用，终身学习且单调改进环境执行验证
RLEF在线 RL：从执行反馈学习，r=通过测试数/总测试数，零 reward 噪声测试套件（确定性）
