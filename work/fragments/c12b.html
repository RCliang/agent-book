GRPO 变体动物园DAPO · GSPO · CISPO · GOPO · …

基础 GRPO 暴露四类失败:预训练偏差稀释梯度、对称 clipping 限制探索、组大小浪费、多目标 reward 失衡——变体家族逐一击破,TRL 大多 loss_type 一键切换。

变体解决什么关键机制何时用
DAPO对称 clip 限探索;全对全错组零梯度Clip-Higher εhigh=0.28 · token 级 loss · 动态采样长推理;GRPO 不稳定时首选
GSPOoff-policy 下逐 token ratio 乘积爆炸(1050)序列级几何平均重要性采样,整序列只 clip 一次steps_per_generation>1
Dr. GRPO预训练常见 token 稀释梯度按 (1−πref) 降权,聚焦有信息 token(需 ref_model)词表分布严重不匹配
2-GRPO大 G 生成算力浪费G=2,隐式 DPO 式对比;生成省 8×、端到端 4-6×通过率适中的推理任务
SAPO硬 clip 的梯度悬崖效应sigmoid 软门控,温度 τ±=1.0/1.05;τ→0 回 PPOclip 边界训练不稳
TIS / MISvLLM 与训练前向概率不匹配截断修正(C=5)/ 超阈整条置零(C=3)用 vLLM 生成时建议常开
VESPO启发式改 clip 缺乏原理变分核:平滑、非对称、指数衰减陈旧轨迹异步 / off-policy 训练
DPPOratio clip 对低概率 token 过罚直接 TV/KL 散度做信赖域(binary/topk mask)研究阶段;概率高度偏斜任务
CISPO组内基线不稳,单一 prompt 主导batch 级 reward 缩放 + token 级 loss 协同大规模 RL 推荐默认(ScaleRL)
GDPO高方差 reward 主导,advantage 坍塌每项独立归一化,再按权重 wn 聚合多目标(正确性+格式)
GOPORM 绝对分数幅度无意义只用组内序数 rank 作 advantage,对单调变换不变不可验证奖励(摘要/聊天)
选型速记可验证奖励→GRPO/DAPO;主观 RM 任务→GOPO;off-policy→GSPO/VESPO;开 vLLM→TIS/MIS;大规模→CISPO。
