DPO 训练步:两条序列一个 lossPOLICY / REF · IMPLICIT REWARD · LOGSIGMOID

书 6.5.7 的 PyTorch 风格伪代码:policy 对 chosen/rejected 各算一次序列对数概率,ref 在 no_grad 下给基线,β 缩放差值进 logsigmoid——DPO 的全部数学就这几行。

def dpo_loss(model, ref_model, batch, beta=0.1):
    # ① batch:chosen/rejected 两条序列,prompt 掩为 -100
    logps_chosen   = get_sequence_logprob(model, batch["chosen"])
    logps_rejected = get_sequence_logprob(model, batch["rejected"])
    with torch.no_grad():                ② 参考模型:预计算或在此计算
        ref_logps_chosen   = get_sequence_logprob(ref_model, batch["chosen"])
        ref_logps_rejected = get_sequence_logprob(ref_model, batch["rejected"])
    chosen_rewards   = beta * (logps_chosen - ref_logps_chosen)      ③ β 乘在 logp 差上
    rejected_rewards = beta * (logps_rejected - ref_logps_rejected)
    loss = -F.logsigmoid(chosen_rewards - rejected_rewards).mean()
    return loss

def get_sequence_logprob(model, sequences):
    """仅在回答 token 上求和的对数概率。"""
    outputs = model(sequences["input_ids"], attention_mask=sequences["mask"])
    logits = outputs.logits[:, :-1, :]   ④ 为 next-token 预测做位移
    labels = sequences["labels"][:, 1:]  # 位移后的标签
    log_probs = F.log_softmax(logits, dim=-1)
    token_logps = log_probs.gather(-1, labels.unsqueeze(-1)).squeeze(-1)
    mask = (labels != -100).float()      ⑤ 只对回答 token 求和
    return (token_logps * mask).sum(dim=-1)  # 形状:[batch_size]
①两条序列同批一次前向
prompt 与回答拼成 [x; yw]、[x; yl] 两条序列,同批一次前向同时得到两个 logp——省一半调度。
②ref 冻结:预计算后驱逐
πref 全程静态:开训前整库前向一次缓存参考 logp,训练中将其驱逐出显存——70B 省约 140GB。
③β 的位置与取值
β·(log πθ−log πref) 即隐式 reward;β 过大梯度饱和、过小更新莽撞——0.1 起步。
④⑤位移与 -100 掩码
logits 去尾、labels 去头,对齐 next-token;另记得 -100 掩掉 prompt 段,只对回答计 loss。
运行precompute_ref_log_probs=True;TRL DPOTrainer 直接吃 chosen/rejected 两列数据即可训练。
