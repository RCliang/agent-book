Agent SkillsDISCOVERY · REGISTRY · VS FINE-TUNING

Skill 思路由 Voyager 在 Minecraft 中推广:可执行代码技能不断入库、验证、复用。如今 skill 以可版本化的包封装领域专长——不重新训练即可加载、组合与替换,可扩展性远超任何单个 prompt。

5能力要素:prompt·工具·知识·工作流·护栏
3架构模式:静态加载·动态发现·层级 DAG
6生命周期:发现→选择→激活→执行→失活→学习
5Anthropic 构建块模式,可作 skill 模板
01Skill ≠ Tool
Skill=完整能力包:prompt+工具+知识+工作流+护栏;Tool 仅单次函数调用。Tool 是锤子,Skill 是建房框架,Agent 是选 skill 的木匠。
02三种架构模式
静态加载:初始化即全量载入,低延迟但费上下文窗口;动态发现:路由器按任务激活,可扩至数百 skill;层级组合:依赖成 DAG,子 skill 可被多个父共享。
03案例:Anthropic 设计
增强型 LLM = Model+Retrieval+Tools+Memory。最有效的是配好工具的简单循环——智能来自模型、工具描述质量与任务清晰度,而非花哨编排。
图:Skill 动态发现——路由器按任务从注册表匹配 top-3,仅激活项注入上下文,执行后失活释放窗口
Skill vs 微调两者互补:微调提供基础能力(指令跟随·工具格式·推理),skill 在运行时叠加任务专长——即时部署、可组合、多租户可各异;深层参数级改变仍需微调。
