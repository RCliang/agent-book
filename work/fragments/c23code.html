生产级 Agent Harness 骨架CONTEXT BUDGET · TOOL DISPATCH · REACT LOOP

书 18.10:system 消息与四段 token 预算、按名分发的工具执行器、ReAct 主循环——模型→解析工具调用→执行→回填观测,四重终止条件兜底,永不静默死循环。

class AgentHarness:
    def __init__(self, model, system_prompt, tools, approval_cb=None):
        self.executor = ToolExecutor(tools, approval_cb)  ① 工具分发表
        self.ctx_mgr = ContextManager(model, max_tokens=128_000)
        self.ctx_mgr.system_msg = Message(Role.SYSTEM, system_prompt)
    async def run(self, user_input: str) -> str:  # user 消息先入 context
        tool_defs = [t.to_api_dict() for t in self.tools]
        tool_tokens = sum(self.ctx_mgr.count_tokens(  ② 组装时计预算
            json.dumps(t)) for t in tool_defs)
        for iteration in range(self.MAX_ITERATIONS):  # 硬上限 50
            if not self.ctx_mgr.preflight_check(tool_tokens):
                return "I've run out of context space."  ③ 每轮预算闸
            response = await self.client.chat.completions.create(
                model=self.model, messages=self.ctx_mgr.build_messages(),
                tools=tool_defs, tool_choice="auto", temperature=0.0)
            choice = response.choices[0]
            if choice.finish_reason == "stop" or not choice.message.tool_calls:
                return choice.message.content or "Task complete."  ④ 终止
            results = await self._execute_tool_calls(choice.message.tool_calls)
            for tid, result in results.items():  ⑤ 观测回填
                self.ctx_mgr.add_message(Message(
                    Role.TOOL, result, tool_call_id=tid))
①工具分发表
ToolExecutor 以 {name: 定义} 建表,按模型给出的名字分发执行——工具多也不乱。
②③预算为何在组装时算
工具 Schema 开始时序列化计数一次,每轮 preflight 复核——预算前置,防静默溢出。
④循环终止条件
终止:stop 或无 tool_calls 正常返回;预算溢出坦白求新会话;LoopDetector 断死循环。
⑤观测回填要「对位」
结果以 role=TOOL + tool_call_id 与调用一一配对回填;多工具 gather 并行。
运行依赖 openai sdk;预期:模型按需调用工具、观测回填后继续,直至 stop 终止。
