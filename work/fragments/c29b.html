A2A:协调、发现与安全PATTERNS · CNP · A2A × MCP

从请求-响应到合同网与拍卖,A2A 提供一整套通信与协调语汇;它与 MCP 纵横互补——MCP 纵向连工具,A2A 横向连 Agent,生产系统两者并用。

01通信模式全景
七种:请求-响应·流式·多轮·广播·pub-sub·协商·拍卖,按延迟与任务复杂度选;流式让审阅与生成并行,总延迟降 40-60%。
02发现与路由
注册中心:中心化简单但单点,联合更韧性、宜跨组织;按能力语义匹配 Agent Card 路由;均衡:轮询/最少负载/延迟感知/亲和;语义化版本防偏斜。
03协调协议
合同网:宣告→竞标→授标→汇报;黑板:共享工作区、机会主义求解;共识:多数/加权/法定人数/德尔菲;领导者选举应对编排器失效。
维度MCP(纵向)A2A(横向)
参与方Agent ↔ 工具/资源Agent ↔ Agent
