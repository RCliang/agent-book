R1 · o1 · 可验证奖励DEEPSEEK-R1 · O1/O3 · RLVR

DeepSeek-R1 两阶段全透明:冷启动 SFT + GRPO;可验证奖励(RLVR)下仅结果奖励即足以涌现推理——aha 时刻自然发生。

01R1-Zero:纯 RL 的顿悟
基座直接纯 RL 不稳(混语、重复循环),却涌现「Wait, let me reconsider…」自我纠正——aha 时刻纯由准确率目标涌现。
02奖励:可验证即足够
r = racc + 0.1·rfmt:SymPy/测试用例验答案,查 think/answer 标签;不用 PRM——PRM 反引入步级奖励黑客。
图:R1 训练流程(书 p259)· 上行主链自 DeepSeek-V3 至 R1;下行蒸馏分支产出 R1-Distill 系列
03GRPO:组相对策略优化
每题采 G=8 答,优势 Âi=(ri−μr)/σr 组内归一化;clip+KL 罚;全对/全错组零梯度——自然聚焦能力前沿。
04R1-Distill 蒸馏
R1 生成→过滤→SFT 小模型(1.5B–70B);7B 蒸馏胜过 7B 从零 RL——小模型缺探索,不缺表示。
05OpenAI o1 / o3
隐藏推理 token 不展示:无格式约束、无风格作弊;据信 PRM+ORM;AIME'24 83%(GPT-4o 13%)、o4-mini 93%。
06QwQ / Qwen 多阶段 RL
基座→SFT→拒绝采样 RFT→GRPO 两阶段 RL;比纯 RL 稳、比纯 SFT 强;推理链内调 Python 工具验证。
07Journey · Quiet-STaR
Journey Learning 连失败与纠正一起训练(负样本+纠错);Quiet-STaR 每 token 位置思考,代价 ×(Lz+1)。
08过度思考与算力权衡
链过长误差累积,准确率 U 形;思考占比按难度 30%/80%/95%;训练与测试算力可互换,最优占比 α/(α+β)。
