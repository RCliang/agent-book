一个 GRPOConfig 展开整个组G=8 · TEMPERATURE 1.0 · REWARD FUNCS

书 7.3 最小可运行示例:每条 prompt 采 8 条响应、组统计量当 baseline,critic 从显存中消失;reward 就是一个普通 Python 函数。

from trl import GRPOConfig, GRPOTrainer
model = AutoModelForCausalLM.from_pretrained(
    "Qwen/Qwen2.5-7B-Instruct", torch_dtype=torch.bfloat16,
    attn_implementation="flash_attention_2")
grpo_config = GRPOConfig(
    num_generations=8, temperature=1.0,   ① G=8 · 高温保组内多样
    max_completion_length=2048, beta=0.04, ③ KL 惩罚系数
    learning_rate=1e-6,
    per_device_train_batch_size=2,        ② 每设备 2 prompt ×8 = 16 响应
    use_vllm=True)                        ④ 8 倍生成,速度至关重要

def reward_fn(completions, prompts, **kwargs):  ⑤ Python 函数即 reward
    """返回 float 列表:正确为 1.0,错误为 0.0。"""
    rewards = []
    for completion, prompt in zip(completions, prompts):
        answer, expected = extract_answer(completion), get_ground_truth(prompt)
        rewards.append(1.0 if answer == expected else 0.0)
    return rewards

trainer = GRPOTrainer(model=model, args=grpo_config,
    reward_funcs=[reward_fn, format_reward_fn],  ⑤ 可组合多个,多目标
    train_dataset=math_dataset, tokenizer=tokenizer)
trainer.train()
①②配置如何展开一个组
每条 prompt 采 G=8 条响应,每设备 2×8=16 条进 batch;组均值当 baseline,critic 从显存消失。全对/全错则 advantage 全 0——温度 1.0 就是为组内留差异。
③β=0.04:KL 只当护栏
KL 项是防模式坍塌的主要多样性机制,不是学习信号本体——信号来自组内归一化 advantage,所以这个系数默认设得很小。
④生成是开销大头
GRPO 每步要为每条 prompt 生成 8 倍响应,速度至关重要;use_vllm 把生成引擎换成 vLLM(书中配 0.7 的显存占用),训练才跑得动。
⑤签名决定接入方式
reward 函数收 (completions, prompts, **kwargs)、返回 float 列表;reward_funcs 可并列多个(正确性+格式),多目标各算各的、直接相加。
运行pip install trl · 一行启动:trainer.train();预期:日志 reward 均值逐步上升——组内高于均值的响应 advantage 为正、低于均值为负。
