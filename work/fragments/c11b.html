DPO 陷阱与变体家族PITFALLS · BETA GUIDE · VARIANT FAMILY

DPO 简单但陷阱密布:不掩码的 prompt、均值代求和、过期的 reference 都会静默失败;八个变体针对各自的失败场景对症下药。

0.05激进 · 数据好,要明显改进
0.1标准 · 默认起点,质量稳定性平衡
0.2保守 · 噪声多或已近期望行为
0.5非常保守 · 安全微调,保住能力
01陷阱 · 忘记掩码 prompt
prompt token 混入求和 → 优化「prompt 似然」(无意义),有效 β 也算错。
02陷阱 · 均值代求和
长回答对数概率天然更低;均值与求和隐式长度惩罚不同,πθ 与 π_ref 必须一致。
03陷阱 · reference 过强/过弱
base 对微调模型相距过远 → KL 主导、梯度消失,应改用 SFT checkpoint;过强 policy 动弹不得,过弱失去正则化。
变体核心改动解决的失败场景
f-DPOf′ 替换对数比,推广 f-散度反向 KL 寻峰,多样性差
Robust DPO(1−ε)L(w,l)−εL(l,w) 除以 1−2ε标签噪声、标注翻转
TR-DPOEMA 周期更新 reference,α 混入 policyreference 过期,KL 主导早平台
EXO对调 πθ 与 π_ref 角色,纠正反向 KLloss 实为前向 KL,方向错
NCA加绝对似然项,防被选概率同跌似然崩塌:被选也被压低
SLiC-HFhinge 损失 max(0, δ−margin)大 margin 时 log-sigmoid 收敛慢
Iterative RPO被选上加 NLL:λ1·L_DPO+λ2·L_NLL会判别不会生成,推理退化
SimPO免 reference:β/|y|·log πθ + margin γreference 显存翻倍、复杂
驱逐 referenceπ_ref 全程静止:预计算 reference 对数概率、缓存磁盘后逐出 → 显存腾出,B_micro 1-2→4-8,70B 约省 140GB。
