Agent Harness:上下文工程CONTEXT WINDOW · PROMPT · TOOLS

模型与真实任务之间隔着一层基础设施:harness 管记忆、路由工具、跟踪状态、强制安全——设计糟糕会抵消最强 LLM,设计良好则放大中等模型。

01什么是 Harness
包裹模型的运行时层:把无状态文本补全引擎变成有状态、目标导向的 Agent。模型是「大脑」,harness 是它的「操作系统」。
02Context 预算与压缩
H 随对话无限涨,超限先压缩:滑动窗口、旧轮摘要(短 5-10×)、按相关性保留。递归语言模型 RLM 分块调用,规避 context rot。
03Prompt 架构
System prompt 四件套:人格·能力·约束·输出格式;运行时按块组装、独立版本化;few-shot 按相关性选例并轮换。
04工具·安全·MCP
签名五要素:名称·描述·参数·输出·约束;大库检索预筛 top-k;输出截断+错误归一;沙箱执行防注入;MCP 统一接入——详见 CH 22。
