模型不仅决定说什么,还决定如何呈现:工具调用直接渲染为界面组件。流式是基线,审批门控必须分层,信任则是涌现的属性——北极星是「透明协作者」。

01生成式 UI · RSC
工具调用渲染为 React Server Component 流式注入;模型按内容类型从精选、可访问、安全的组件库中选择。
02流式与实时
Token / 工具调用 / 多 Agent 三种流,SSE 主导;背压:50-100ms 批量、10Hz 节流;操作乐观更新。
03人机协同 · HITL
打断五判据:可逆性·影响范围·置信度·成本·新颖性;内联纠正与偏好选择既是反馈,也是教学信号。
