Agent 设计模式WORKFLOW & AGENT PATTERNS

架构决定 Agent 是否可靠、可调试且成本可控。工作流预定义控制流——可预测、可测试、更便宜;Agent 由 LLM 动态决策——灵活、应对新情况。从工作流开始,确需自适应才升级。

自主 Agent 模式工具调用模式 ×5
01ReAct
思考→行动→观察循环;草稿本记思考,上限 10-25 次,final_answer 终止。
02规划型 Agent
先出显式计划,随观察修订;依赖按 DAG 跟踪——计划是活文档。
03反思与自我批判
校验输出、回顾轨迹、修订策略;Reflexion 记忆跨回合学习。
04工具调用五式
单轮·多工具并行·顺序·嵌套·回退;降级由 harness 透明处理。
设计原则保持简单、透明优于聪明、良好工具、为失败规划、结构化输出;模式可组合——艺术在于知道何时停止增加层次。
