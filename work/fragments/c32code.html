书 27.9:FastAPI 生成器产出 SSE 事件流;不可逆操作先推审批事件,再在 asyncio.Event 处挂起——流不断、Agent 停,人点头后才继续。

async def agent_stream(session_id: str, user_message: str):
    def sse(event_type: str, data: dict) -> str:
        return f"data: {json.dumps({'type': event_type, **data})}\n\n"
    approval_id = f"{session_id}_email_001"        ② Tier 3 审批门控
    approval_store[approval_id] = ev = asyncio.Event()
    yield sse("approval_required", {"approval_id": approval_id,
            "tool": "send_email", "tier": 3, "risk": "irreversible"})
    try:
        await asyncio.wait_for(ev.wait(), timeout=300)  ③ 挂起整条流
        ...  批准 → 执行 send_email;拒绝 → action_rejected
    except asyncio.TimeoutError:
        yield sse("approval_timeout", {"approval_id": approval_id})
    yield sse("token", {"content": "I've completed the research. "})
@app.get("/chat/stream")                     ① SSE 主通道
async def chat_stream(session_id: str, message: str):
    return StreamingResponse(agent_stream(session_id, message),
                             media_type="text/event-stream")
@app.post("/chat/approve")                    ④ 批准端点 → 恢复
async def handle_approval(req: ApprovalRequest):
    approval_results[req.approval_id] = {"approved": req.approved,
                                         "parameters": req.parameters}
    approval_store[req.approval_id].set()   set() 唤醒挂起的流
①SSE 是 Agent UI 主通道
一条 SSE 连接混排 status/thinking/tool_call/tool_result 事件,前端按类型分别渲染。
②门控即打断
send_email 命中 Tier 3 清单:emit approval_required 后 await 事件挂起等待。
③限时兜底,拒绝也有终态
等 300 秒不批则 approval_timeout、动作跳过——门控不会变成死锁。
④POST 批准,原地恢复
前端 ApprovalGate 渲染按钮,POST /chat/approve 唤醒,原地恢复执行;乐观更新先显结果。
运行依赖 fastapi;uvicorn main:app 启动,浏览器开 /chat 发消息,敏感动作即触发审批。
