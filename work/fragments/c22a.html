记忆:类型与架构MEMORY TYPES · ARCHITECTURES

LLM 本质无状态:GPT-4o 上下文 128K Token,而一本典型书籍约 670K——数日运行的 Agent 累积的观察必然溢出。记忆系统是对这一物理约束的工程回应。

01工作记忆 Working
上下文内的工作区:草稿板、思维链、对话历史。零检索延迟,易失,受 L 约束。
02情景记忆 Episodic
过往事件按时间索引:成功轨迹作少样本范例,失败案例带根因标注。
03语义记忆 Semantic
上下文无关的事实与概念:实体关系、领域本体、知识图谱 G=(V,E)。
04程序记忆 Procedural
自动化的技能:工具使用模式、多步动作序列;权重 θ 即程序记忆,微调即巩固。
05为什么需要记忆
滚出窗口即灾难性遗忘;无情景存储,经验无法复用;无用户模型,每轮冷启动。
06五大架构家族
RAG 向量检索 · 摘要压缩 · 知识图谱 · 键值记忆网络 · MemGPT 分层——按容量、延迟、可训练性取舍。
