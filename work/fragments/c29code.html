    while task.status.state not in {"completed", "failed", "canceled"}:

①Agent Card 驱动能力发现
托管于 /.well-known/agent.json 的 JSON 清单,声明 skills、capabilities 与认证方式——编排器据此语义路由,类似面向自主 Agent 的 OpenAPI。
②异步优先:提交即返回
send_task 立即返回 submitted 状态的 Task 而非结果;id 用 uuid4,metadata 带 workflowId/subQuestion——跨 Agent 追踪与交接全靠它。
③生命周期与等待策略
状态机:submitted→working→completed/failed/canceled(另有 input-required)。短任务轮询足够;分钟级长任务应走 SSE 流或 webhook 推送,别挂长连接。
④并行派发,失败不炸
gather 并行派发子问题,收齐后取各任务 artifacts 综合成报告;failed 只告警不中断。A2A 管 Agent↔Agent,与 MCP(Agent↔Tool)互补并用。
