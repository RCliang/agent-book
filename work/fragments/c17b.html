案例：副驾与研究 AgentPRODUCTIVITY COPILOT · RESEARCH AGENT

同一配方跑通两个用例：SFT 示范打底，模拟环境中 GRPO 在线强化，执行 reward 与人类反馈共同塑形——生产力副驾与研究 Agent。

  • SFT：50K–200K 示范轨迹
  • 构建模拟沙盒 · 任务课程
  • GRPO 在线 RL（N=8/任务）
  • 内测 1000+ 用户 · DPO 精调
01POMDP 形式化
动作=六应用 JSON API 调用；状态=工作区投影（部分可观测）；γ=0.99 · 10–50 步。
02多目标 Reward
任务 .40·质量 .25·效率 .15·安全 .15·用户 .05；违规则安全项归零。
03模拟环境与课程
沙盒合成邮箱·日历·文档；L1 单步→L5 跨应用，成功率 >70% 晋级。
04安全护栏 · 信用分配
硬约束（外发·删除·改权限）拒并 −1.0；子目标各 +0.2，失败只罚断裂段。
图 12.2 · 生产力副驾（用例一）：用户意图 → 策略 πθ → 六应用 API；执行 reward 经 GRPO 回流，端到端更新策略
05用例二 · 研究 Agent
GRPO N=4·γ=1.0；R=质量 .30＋正确 .30＋新颖 .15＋效率 .15＋格式 .10。示例：13 步实验 R=0.875，优势 +1.48。
06失败模式与教训
无限循环·调试螺旋·幻觉引用·过早提交·judge hacking；对策：步数预算、重试上限 3、引用验证、轮换 judge。
