class VectorMemoryStore:
    def write(self, content, importance=0.5, check_duplicates=True):
        if check_duplicates and self._is_duplicate(content):  ① 写入过滤
            return None   # 余弦相似度>0.95:近似重复,直接跳过
        if len(self.entries) >= self.max_entries:
            self._evict()  # 满:逐出「最不重要×最久未访」条目
        self.entries.append(MemoryEntry(content=content,
            embedding=self.embed_fn(content), importance=importance))

①写什么:写入有门槛
写入有门槛:与现有记忆余弦相似 >0.95 判近似重复丢弃;容量满按「重要性×时近」驱逐。
②怎么读:混合打分
混合打分 score=(1−0.3)·余弦 + 0.3·e^(−λ·age):相似为主、时间衰减兜底,取 top-k。
